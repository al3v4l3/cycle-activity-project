# Automatisierte Tests

Hier werden mit der Implementierung die ausführbaren Tests ergänzt. Das konkrete Testwerkzeug folgt aus der Technologieentscheidung. Frameworktypische Tests können bei Bedarf direkt neben dem zugehörigen Anwendungscode liegen.

Die fachlichen Akzeptanzfälle stehen bereits in [Erhebung und Qualität](../docs/07-erhebung-und-qualitaet.md). Vorhandene Testbeschreibungen sind keine erfolgreich ausgeführten Tests. Jede umgesetzte Story erhält passende Prüfungen; eine Test-Suite existiert derzeit noch nicht.
