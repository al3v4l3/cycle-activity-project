# Technikauswahl

**Status: offen**

## Entscheidungen

| Bereich | Kriterien |
| --- | --- |
| Sprache und Oberfläche | Mobile Formulare, verständliche Darstellung, vorhandene Kenntnisse, Testbarkeit |
| Speicherung | Erhalt nach erneutem Öffnen, Löschung, Gerätewechsel, Zugriff und Betriebsaufwand |
| Entwicklungs- und Testwerkzeuge | Gemeinsame Nutzung, reproduzierbarer Start und nachvollziehbare Prüfungen |

Für die wichtigsten Entscheidungen werden passende Optionen verglichen. Die Auswahl wird mit Alternativen, Begründung und Konsequenzen in der [Entscheidungsübersicht](entscheidungen.md) dokumentiert.

## Wiederverwendung

Vorhandene Bibliotheken oder Schnittstellen werden eingesetzt, wenn sie eine Anforderung sinnvoll unterstützen. Dafür sind Zugang, Plattform, Lizenz und Aufwand zu prüfen. Unsichere Integrationen werden zunächst mit einem begrenzten Versuch untersucht.

Der manuelle Kernablauf benötigt keine externe API. Kandidaten für spätere Erweiterungen stehen in der [Recherche](06-recherche.md).
