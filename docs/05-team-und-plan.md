# Arbeitsplan

## Arbeitsschritte

| Schritt | Ergebnis |
| --- | --- |
| Ziel konkretisieren | Produktziel und Erfolgskriterien |
| Anforderungen festlegen | Funktionen, Qualitätsregeln und Eingaberegeln |
| Backlog ordnen | Priorisierte Stories mit Kriterien und Aufwand |
| Entwurf erstellen | Ablauf, Ansichten und Datenmodell |
| Technik auswählen | Begründete Auswahl von Sprache, Oberfläche und Speicherung |
| Unterlagen prüfen | Lücken und Widersprüche bearbeitet |
| Erste Umsetzung | Kleiner durchgängiger Ablauf mit passenden Tests |
