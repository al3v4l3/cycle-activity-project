# Projektwerkstatt · Software Engineering verstehen

Ein eigenständiger interaktiver Lernbegleiter für neue Mitglieder unseres Viererteams. Er erklärt die projektbezogenen Inhalte der bereitgestellten Vorlesung von Grund auf und verbindet sie mit unserem Repository. Fertiggestellt am 18.11.2026; die Projektbeispiele beziehen sich auf den Startstand vom 11.11.2026.

## Öffnen und weitergeben

1. [index.html auf GitHub öffnen](https://github.com/al3v4l3/cycle-activity-project/blob/main/lernen/index.html) und über **Download raw file** herunterladen. GitHub zeigt in der normalen Dateiansicht den Quelltext, nicht die Lernoberfläche.
2. Die heruntergeladene HTML-Datei in einem aktuellen Browser öffnen. Auf dem Rechner genügt normalerweise ein Doppelklick; andernfalls „Öffnen mit“ → Browser wählen.
3. Die einzelne Datei kann ans Team weitergegeben werden. Es sind keine Installation, Anmeldung oder externen Bibliotheken nötig. Kapitel und Übungen sind ohne Internet nutzbar; Links zu GitHub und Quellen benötigen Internet.

Wer das Repository bereits lokal hat, öffnet `lernen/index.html`. Auf dem Smartphone kann eine Dateivorschau JavaScript einschränken; die Datei in einem Browser öffnen. Das Verhalten lokaler Dateien und Downloads hängt vom Browser ab.

## Fortschritt und Export

Lernmarkierungen, Notizen, Story-Entwurf und Quizantworten werden ausschließlich im lokalen Browser gespeichert, soweit dieser es zulässt. Sie werden nicht ins echte Board oder Repository übertragen. Ein anderer Browser oder gelöschte Browserdaten können den Fortschritt verlieren.

**Notizen exportieren** und der Story-Export zeigen zuerst den vollständigen Markdown-Inhalt. Er kann als Datei gespeichert oder über **Text markieren** kopiert werden. So bleibt der Export auch zugänglich, wenn ein eingebauter Browser den Dateidownload einschränkt.

**Drucken / PDF** öffnet den Druckdialog für eine Lesefassung aller Kapitel und Quellen. Dort kann in geeigneten Browsern „Als PDF speichern“ gewählt werden. Interaktive Übungen funktionieren in der HTML-Fassung; eine druckfertig geprüfte separate PDF-Datei ist nicht enthalten.

## Grundlage und Pflege

Der Kurs fasst die bereitgestellten Unterlagen in eigenen Worten zusammen. Unter jedem Kapitel stehen Fundstellen, die Quellenübersicht nennt Abdeckung und Grenzen. Originalunterlagen und private Screenshots sind nicht eingebettet. Offene Abgabevorgaben werden als offen bezeichnet; Lehrinhalt, Team-Mitschrift und Projektvorschlag sind kenntlich gemacht.

Aktuelle Teamentscheidungen stehen in den Projektdokumenten. Der Lernbegleiter muss bei Änderungen von Anforderungen oder Arbeitsablauf gezielt mitgeprüft werden. Er ist keine offizielle Bewertungsmatrix und keine Zusicherung, dass alle späteren Vorlesungsinhalte abgedeckt sind.

## Geprüfter Stand

Desktop- und Smartphone-Darstellung, Navigation, Story-Vorschau, Wiederherstellung von Notizen und Fortschritt, Kapazitätsänderungen, Übungsboard, Zustandsübung und Quiz-Auswertung wurden im Browser geprüft. Exportinhalte werden vor einem Download als lesbarer Text bereitgestellt. Ein tatsächlicher Dateidownload und die Druckausgabe müssen im jeweils verwendeten Browser geprüft werden.
